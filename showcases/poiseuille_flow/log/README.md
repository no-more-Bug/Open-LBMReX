# Case logs

This directory belongs to the poiseuille_flow showcase and holds terminal/runtime logs for explicit case runs. Keep these separate from numerical artifacts in [outputs](../outputs/README.md). Use a distinct log path for each run; redirect stdout/stderr explicitly when needed.

Generated logs are not part of the source snapshot. See the [case README](../README.md) for the input and output contract; a zero solver exit does not replace scientific acceptance.
