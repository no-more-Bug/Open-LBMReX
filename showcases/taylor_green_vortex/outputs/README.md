# Generated numerical output

This directory belongs to the taylor_green_vortex showcase. Store its generated CSVs, plotfiles and analysis products here, using the output controls described in the [case README](../README.md). They are distinct from tracked scientific reference data.

Generated results are not shipped with the source snapshot. A plot or completed run is not by itself a scientific pass; retain the case identity, horizon, checker result and applicable limitations with any result you report. Other tests or unrelated cleanup must not remove these research artifacts.
